<h1 align="center">뱅크샐러드 카드 실적 위젯</h1>

<p align="center">
  뱅크샐러드 앱을 열지 않고도 카드별 이번 달 실적을 홈 화면에서 바로 확인하는 안드로이드 위젯입니다.
</p>

---

## 무엇을 하나요?

뱅크샐러드의 `카드 혜택 > 실적 관리` 화면에는 카드마다 이번 달 사용액, 실적 목표, 남은 금액이 표시됩니다. 이 앱은 그 숫자를 홈 화면 위젯으로 보여 줍니다.

```
카드 실적                         10.1~10.31
A 신용카드                               완료
████████████████████  412,300원 / 30만원
B 체크카드                     41,500원 남음
████████████████░░░░  258,500원 / 30만원
3시간 전 갱신
```

- 카드마다 카드명, 진행 막대, `완료` 또는 `N원 남음`, 사용액과 목표를 표시합니다.
- 상단에는 실적 기간을 표시하고, 달이 바뀌었는데 아직 새 값을 읽지 못했다면 `지난달`이라고 알려 줍니다.
- 하단에는 마지막으로 갱신에 성공한 시각을 표시합니다. 갱신에 실패했거나 값이 24시간보다 오래되면 주황색으로 경고합니다.

## 어떻게 동작하나요?

뱅크샐러드 서버를 직접 호출하지 않고, **사람이 화면에서 보는 글자를 안드로이드 접근성 기능으로 읽습니다.** 그래서 위젯의 숫자는 뱅크샐러드 앱에 표시된 값과 정확히 같습니다.

1. 기기 잠금을 직접 해제하면, 마지막 갱신 후 6시간이 지났을 때만 자동 갱신을 시작합니다. 위젯을 탭하면 즉시 갱신합니다.
2. 갱신하는 동안에는 `실적 갱신 중…` 덮개가 화면을 가립니다. 덮개를 누르면 갱신을 바로 중단할 수 있습니다.
3. 뱅크샐러드의 실적 관리 화면을 띄우고, 화면 값이 안정될 때까지 여러 번 읽은 뒤 카드별 실적을 파싱합니다.
4. 결과를 저장하고 홈 화면으로 돌아간 뒤 위젯을 다시 그립니다.

### 하지 않는 것

- 뱅크샐러드 APK를 변조하거나 리패키징하지 않습니다.
- 서버 API를 호출하거나 인증 토큰을 추출하지 않습니다.
- 기기 보안 잠금을 자동으로 해제하지 않습니다. 그래서 자동 갱신은 사용자가 잠금을 해제한 뒤에만 일어납니다.
- 뱅크샐러드 외의 앱 화면은 읽지 않습니다. 접근성 서비스는 `com.rainist.banksalad2` 패키지로만 제한되어 있습니다.

## 설치

1. [Releases](https://github.com/wonss737/banksalad-spend-requirement/releases)에서 최신 `app-debug.apk`를 내려받아 설치합니다. Play 스토어에는 배포하지 않습니다.
2. `설정 > 접근성 > 설치된 앱 > 뱅크샐러드 카드 실적 위젯`을 켭니다.
3. 홈 화면을 길게 누르고 `위젯`에서 `뱅크샐러드 카드 실적 위젯`을 추가합니다.
4. 위젯을 한 번 탭해서 첫 실적을 불러옵니다.

요구 사항: Android 12(API 31) 이상, 뱅크샐러드 앱 설치 및 로그인.

## 직접 빌드하기

JDK 17 이상과 Android SDK(API 35)가 필요합니다.

```bash
cd widget
./gradlew testDebugUnitTest   # 단위 테스트
./gradlew assembleDebug       # APK 생성
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

빌드한 APK는 `widget/app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다.

## 프로젝트 구조

```
widget/app/src/main/java/com/wonhy/cardperf/
├── parse/      실적 화면 텍스트를 카드별 데이터로 변환 (PerfParser, Money)
├── policy/     갱신 쿨다운, 읽기 안정화, 세션 보호, 위젯 상태 문구 규칙
├── service/    접근성 서비스, 갱신 세션, 덮개 오버레이
├── store/      SharedPreferences 저장소
├── widget/     홈 위젯 프로바이더와 수동 갱신용 트램펄린 액티비티
└── MainActivity.kt   권한 상태와 최근 실적을 보여 주는 화면
```

설계 배경과 결정 사항은 [`docs/superpowers/specs`](docs/superpowers/specs)에 정리되어 있습니다.

## 한계

- 접근성 서비스는 전면에 떠 있는 창만 읽을 수 있으므로, 갱신할 때 뱅크샐러드가 몇 초 동안 화면에 뜹니다(덮개로 가립니다).
- 뱅크샐러드가 업데이트되어 실적 화면의 문구나 구조가 바뀌면 파싱 규칙을 고쳐야 할 수 있습니다.
- 개인 기기에서 쓰려고 만든 비공식 도구이며, 뱅크샐러드(Rainist)와 관련이 없습니다.
